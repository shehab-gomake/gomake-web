# GoMake Web - Project Overview

## Purpose
GoMake Web is a manufacturing management web application built with Next.js. It includes a unified communication hub called FrontDesk that integrates multiple messaging providers (Gmail, WhatsApp, Internal messaging) into a single interface.

## Tech Stack
- **Framework**: Next.js 13 with Pages Router (NOT App Router)
- **Language**: TypeScript (non-strict)
- **State Management**: Recoil
- **UI Libraries**: MUI (Material-UI v5), Ant Design, PrimeReact
- **Data/Real-time**: Axios with custom hooks, SignalR
- **Styling**: styled-components, Emotion
- **Testing**: Jest + React Testing Library
- **Development**: Node.js with npm

## Key Features
- Manufacturing management system
- FrontDesk unified communication system
- Multi-provider messaging (Gmail, WhatsApp, Internal)
- Real-time updates via SignalR
- OAuth authentication for external providers
- Comprehensive UI component library

## Current Focus
The project is currently working on Reply Box Ergonomics improvements for the FrontDesk system, focusing on faster replies with hotkeys, autosave, and better user feedback.
