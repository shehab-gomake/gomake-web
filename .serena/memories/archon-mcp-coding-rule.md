# Archon MCP Knowledge Base & RAG Coding Rule

## Mandatory Practice: Always Use Knowledge Base When Coding

When coding, I MUST actively use the Archon MCP Knowledge Base & RAG capabilities:

### Required Actions:
1. **Search knowledge base using RAG queries** - Before implementing any feature or fixing issues
2. **Find code examples** - Look for relevant implementation patterns and examples
3. **Get available sources and domains** - Check what documentation is available
4. **Perform semantic searches across documentation** - Find best practices and solutions

### Implementation Workflow:
1. **Before Coding**: Search knowledge base for relevant patterns, best practices, and examples
2. **During Development**: Reference documentation for API usage and validate against best practices
3. **When Debugging**: Search for troubleshooting solutions and common issues
4. **After Implementation**: Look for optimization opportunities and security considerations

### Key Benefits:
- Up-to-date information from official documentation
- Real code examples from authoritative sources
- Prevention of common pitfalls
- Enhanced code quality and reliability
- Continuous learning and improvement

### Example Usage:
- Socket.IO implementation → Search for connection patterns, authentication, error handling
- NestJS development → Find dependency injection patterns, module structure examples
- Authentication systems → Look for security best practices and implementation guides
- Performance optimization → Search for tuning recommendations and monitoring patterns

This rule ensures every piece of code is informed by the latest best practices and official documentation available in the Archon MCP Knowledge Base.
