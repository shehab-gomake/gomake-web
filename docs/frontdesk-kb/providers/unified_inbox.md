# Unified Inbox

The Unified Inbox is a special provider that aggregates conversations from all other providers into a single, unified list.

- **Status**: **Partial**.
- **Functionality**: Aims to aggregate conversations from all providers into a single list.
- **Known Gap**: The Unified Inbox can successfully render the aggregated list of conversations, but it cannot yet display the messages for a selected conversation. Completing this feature requires creating a dynamic view that can render the appropriate message viewer component based on the selected conversation's `provider` metadata.
