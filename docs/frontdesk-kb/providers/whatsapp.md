# WhatsApp

The WhatsApp provider is intended to integrate with the WhatsApp Business API.

- **Status**: **Partial / Mock Data**. This provider is not currently connected to a real API.
- **Functionality**: The UI is built, but it operates on mock data.
- **Task**: To complete this provider, the mock data in `use-whatsapp-provider.ts` needs to be replaced with real API calls and WebSocket subscriptions, following the patterns established in the other providers.
