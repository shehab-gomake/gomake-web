# FrontDesk Orchestrator State

This directory contains persistent state files for the `frontdesk-orchestrator` agent.

## Files

### `frontdesk-tasks.json`

**Status**: Session-specific (gitignored)

Task graph with all FrontDesk feature tasks, including:

- Task IDs, names, and descriptions
- Acceptance criteria and Definition of Done
- Dependencies and blockers
- Status tracking (pending/in-progress/completed/blocked)
- Complexity estimates and velocity metrics

**Schema**: See [frontdesk-orchestrator.md](../.claude/agents/frontdesk-orchestrator.md#-state-persistence-schema)

**Usage**:

- Auto-loaded by orchestrator agent on startup
- Auto-saved after every task update
- Provides continuity across sessions

### `demo-checklist.md`

**Status**: Version controlled

Demo readiness checklist with:

- Critical path items (must-have features)
- Important items (should-have features)
- Nice-to-have items (could-have features)
- Blockers and risks
- Demo script validation steps
- Pre-demo readiness checklist

**Usage**:

- Updated by orchestrator as features complete
- Guides prioritization and scope decisions
- Tracks demo readiness status

## How It Works

1. **On Agent Startup**: Orchestrator reads both files to load current state
2. **During Development**: State updated as tasks progress
3. **On State Change**: `frontdesk-tasks.json` auto-saved (demo checklist manually updated)
4. **Across Sessions**: State persists, providing continuity

## Manual Edits

You can manually edit these files if needed:

- **Tasks JSON**: Edit carefully to maintain schema validity
- **Demo Checklist**: Feel free to add/remove items as requirements change

## Resetting State

To start fresh:

```bash
# Reset task graph (will be regenerated by orchestrator)
echo '{"version":"1.0.0","lastUpdated":"","metadata":{"totalTasks":0,"completedTasks":0,"blockedTasks":0,"velocity":0,"targetDemoDate":null},"tasks":[]}' > .claude/orchestrator-state/frontdesk-tasks.json

# Demo checklist should be manually reviewed before resetting
```

## Version Control

- **`frontdesk-tasks.json`**: Gitignored (session-specific)
- **`demo-checklist.md`**: Committed (shared requirements)
- **`README.md`**: Committed (documentation)
