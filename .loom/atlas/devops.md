# DevOps & Tooling

## Scripts
-   `npm run dev`: Start development server (Port 3004).
-   `npm run build`: Production build.
-   `npm run lint`: Linting.
-   `npm run test`: Jest tests.

## CI/CD
-   **Linting**: ESLint.
-   **Testing**: Jest.

## Configuration
-   `next.config.js`: Next.js configuration.
-   `tsconfig.json`: TypeScript configuration.
-   `.eslintrc.json`: Linting rules.

## Environment
-   **Target**: Production Cloud Run instance (via `messaging-hub-v2` proxy).
-   **Testing Strategy**: No automated testing mandated for this phase. Manual verification only.
